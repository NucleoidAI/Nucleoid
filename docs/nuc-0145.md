## Abstract

- Add only the final reasoning stage `SELECTION |> indegrees`. It returns
  one nonnegative Number for every selected step, in selection order: the
  length of that step's recorded `from` list, including inputs whose own
  steps are not selected. Its results match the accepted
  `(SELECTION).map(step -> step.from.length)` for the same selection.
- Keep the accepted selection, reference coercion, shadowing, observer
  exclusion, structural reactivity and final-projection boundaries.
  Add no prefix form, keyword, token kind, record field or graph mutation.
- The caller's one uniform live-registry draw selected Reasoning
  enhancement. This allocation requests a graph-structure projection for
  explanations, not a general collection helper. Preparation, the required
  Rust-improvement pass and fresh independent evaluation remain pending.

## Motivation

- An explanation's fan-in says how many recorded direct inputs each result
  rests on. `nodes`, `holds` and `edges` already project explanation
  metadata, but none projects each step's input count.
- The accepted spelling materializes step records and reads each `from`
  list through a callback. A final reasoning projection expresses this
  graph query directly and follows changes in the explanation's wiring.
- Preserve every accepted program, including ignored interpolation
  suffixes and parser-accepted runtime errors. New measured cases need
  immutable, behavior-equivalent accepted programs recorded before any
  candidate edit; this continuous Reasoning enhancement requires the
  actual per-case lexer-token check.
