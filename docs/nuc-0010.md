# NUC 10 -- Standard Built-in Objects

```
NUC: 10
Title: Standard Built-in Objects
Author: Can Mingir <canmingir@gmail.com>
Status: Draft
Type: Standards Track
Created: 31-Jul-2026
Requires: 1, 2, 8
```

## Abstract

- Specifies literals, operators, built-in objects, list functions, and class-list functions.
- Every built-in call in an assignment participates in the dependency graph like any other expression.
- Mutating a list re-evaluates whatever depends on it.

## Motivation

- A declarative language is only useful if its standard operations are declarative too.
- A total, a count, or a formatted label must track its inputs, whether it came from an operator or a library call.
- Lists are the common shape of data, so list operations must be dependencies rather than snapshots.

## Rationale

- **Built-ins are not special.** `Math.floor(total / size)` is a dependency on `total` and `size`, exactly as an arithmetic expression would be.
- **List mutation propagates.** `push` and `pop` re-evaluate dependents, so a derived count stays correct without being recomputed by hand.
- **Nucleoid defines its own built-in surface.** Names are chosen for regularity, not inherited wholesale from a host language.

## Specification

### Literals

- Numbers, including negatives and fractions.
- Strings in single quotes, double quotes, or backticks.
- Template literals interpolate with `${...}` and track their dependencies.
- Booleans `true` and `false`, and `null`.
- Lists in brackets; objects in braces with quoted or bare keys.
- Regular expressions between slashes.

```
a = 123
`New ${a} String`
```

- Evaluates to `"New 123 String"`.

```
host = "localhost"
port = 8080
url = `http://${host}:${port}`
```

- After `port = 9090`, `url` is `"http://localhost:9090"`.

### Operators

- Arithmetic: `+`, `-`, `*`, `/`, `%`.
- Comparison: `==`, `!=`, `<`, `>`, `<=`, `>=`.
- Logical: `and` / `&&`, `or` / `||`, `not` / `!`.
- Parentheses group and override precedence.

```
condition = false

assert(condition or true, true)
assert(condition || true, true)
assert(not condition and true, true)
assert(!condition && true, true)
```

```
a = 2
b = 3
c = 4

assert(a + b * c, 14)
assert((a + b) * c, 20)
```

- A comparison may be assigned directly.

```
alarm = reading > threshold
```

- `+` concatenates when an operand is a string, including numbers and dates.

### Indexing and length

- Lists and instance lists are indexed with brackets.
- An index may be a variable, making it a dependency.
- `.length` is a dependency on the collection.

```
options = ["A", "B", "C"]
index = 1
choice = options[index]
```

- `choice` is `"B"`; after `index = 2`, `"C"`.

```
str1 = "ABC"
i1 = str1.length + 1
```

- `i1` is `4`; after `str1 = "ABCD"`, `5`.

### Slicing

- A range is written `[start:end]`; either bound may be omitted.
- A negative bound counts from the end.
- A slice is a dependency on the value it reads.

```
$Meeting.time = Date.now() + " @ " + $Meeting.date.toDateString()
```

- `meeting.time[-17:]` is `"@ Wed Jan 01 2020"`, the last 17 characters.

### Object

- `Object()` creates a plain object.
- A plain object is not an instance, so class-level rules do not apply to it.
- Objects may be nested and assigned to properties or class-level properties.

### Boolean

- `Boolean(false)` creates a boolean value.

### Number

- `Number.MAX_INTEGER` is `9007199254740991`.

### Math

- `Math.pow`, `Math.sqrt`, `Math.floor`, `Math.round`, `Math.max`, `Math.min`.
- Each is a dependency on its arguments.

```
total = 47
size = 10
pages = Math.floor(total / size) + 1
```

- `pages` is `5`; after `total = 100`, `11`.

```
peak = Math.max(a, b)
floor = Math.min(a, b)
```

- With `a` `5` and `b` `9`, `peak` is `9` and `floor` is `5`.
- After `b = 3`, `peak` is `5` and `floor` is `3`.

### String

- `String.fromCharCode` builds a string from a code.
- Instance functions include `.charAt`, `.length`, `.lower`, `.replace`, `.split`, `.join` on lists.

```
$Quality.class = String.fromCharCode(65 + Math.floor($Quality.score / 10))
```

- With score `15`, the value is `"B"`.

```
csv = "NY,GA,CT"
states = csv.split(",")
```

- `states.length` is `3`; after `csv = "NY,GA"`, `2`.

### Date

- `Date()` is the current date; `Date(string)` and `Date(number)` construct one.
- `Date.now()` is the current time; `Date.parse(string)` parses one.
- Instance functions include `.getTime`, `.getYear`, `.toDateString`.
- Dates compare with the ordinary comparison operators.

```
start = Date("2020-1-1")
end = Date("2020-1-2")
duration = end.getTime() - start.getTime()
```

- `duration` is `86400000` and `end > start` is `true`.

```
date3 = Date.parse("04 Dec 1995 00:12:00 GMT")
```

- `date3` is `818035920000`.

### Regular expressions

- A regular expression literal is written between slashes.
- `.test(...)` returns whether it matches.
- It may be used in a conditional over a variable, a property, or a class-level property.

```
if not /^[A-Z]{2}-[0-9]{4}$/.test($Account.code):
    throw 'INVALID_CODE'
```

- A code of `"NY-1234"` is accepted; `"nyc-1"` throws and the previous value is kept.

### List functions

- `push` and `pop` mutate a list and re-evaluate its dependents.
- `filter`, `map`, `reduce`, `find`, `some`, `every`, `slice`, `sort`, `join` are dependencies on the list.

```
prices = [10, 20, 30]
rate = 2
doubled = prices.map(p => p * rate)
```

- `doubled[2]` is `60`; after `rate = 3`, `90`.
- After `prices.push(40)`, `doubled.length` is `4` and `doubled[3]` is `120`.

```
amounts = [5, 10, 15]
total = amounts.reduce((sum, amount) => sum + amount, 0)
```

- `total` is `30`; after `push(20)`, `50`; after `pop()`, `30`.

```
ranked = scores.slice().sort((a, b) => a - b)
```

- Sorting a copy leaves the source order untouched.

- A list held as a property behaves the same way.

```
playlist1.tracks = []
playlist1.count = playlist1.tracks.length
```

- After pushing two tracks, `count` is `2`; after `pop`, `1`.

### Class-list functions

- A class list supports the same functions as a list.
- They depend on the population and on the properties they read.

```
open = Task.filter(t => not t.done).length
```

- Updates when a task's `done` changes and when a task is added.

```
revenue = Order.reduce((sum, order) => sum + order.amount, 0)
```

- Updates when an order is added or an amount changes.

```
ready = Check.every(c => c.passed)
full = Guest.length >= capacity
```

- `Class.length` is the number of declared types.

## Errors

| Condition | Error |
| --- | --- |
| Calling an unknown function of a built-in object | `TypeError("<Object>.<name> is not a function")` |
| Calling an unknown function of a list | `TypeError("<list>.<name> is not a function")` |

- The object name in the message is written as it appears in the statement, for example `Date.wrong`, `Math.wrong`, `String.wrong`, or `list.wrong`.
