## Introduction

- Index of all NUC documents.
- Numbers are assigned once and never changed; version control is the historical record.
- Every NUC is a language or language-development proposal; accepted, implemented claims form the Nucleoid Language Reference.
- Format and conventions follow Python Enhancement Proposals; see [NUC 1](nuc-0001.md).
- Every added or updated proposal gets a fresh evaluation agent. Accept only behavior-preserving rewrites with no per-case lexer token increase; see [NUC 1](nuc-0001.md#proposal-evaluation).
- [README.md](README.md) is the consolidated reference for the website, assembled from these documents.
- [examples.md](examples.md) is the same ground worked as complete programs, taken from `nucleoid.spec.md`.
- [NUC 11](nuc-0011.md) has implemented selections, pipelines, `why`, `affects`, and live structural dependencies; its remaining stages are proposals.
