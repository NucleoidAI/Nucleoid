```

Author: Can Mingir <canmingir@gmail.com>
Status: Draft
Type: Standards Track

Requires: 1, 2
```

## Abstract

- Specifies types, instances, constructors, subtypes, instance lists, and deletion.
- A type declares a class in the state; every instance is registered in that class's list.
- Instances carry an `id`, assigned from the variable name or generated when there is none.

## Motivation

- Rules in Nucleoid are stated over types, not over individual values.
- A type gives those rules something to quantify over: "any device", "every order".
- Keeping instances in a queryable list is what lets a rule read the whole population.

## Rationale

- **A type is a value in the state.** `$Entity` is the class; `Entity` is the list of its instances. Two names because the two are asked different questions.
- **Instances are named by their variable.** `device1 = Device()` gets `id` `"device1"`, so an instance can be addressed later without a separate registry.
- **Redefining a type preserves its instances.** A type declaration is a statement about the state, not a constructor call; re-running it must not discard what exists.
- **Deletion is refused while references remain.** Silently orphaning properties would break the dependency graph, so the state requires it be emptied first.

## Specification

### Declaring a type

- `class` declares a type in the state.
- An empty body is written `pass`.
- `typeof $Name` is `Class`; `typeof Name` is `List`.
- Every declared class is added to the global `Class` list.

```
class Entity:
    pass
```

- `typeof $Entity` is `Class`.
- `Class.length` counts declared types.

### Constructors

- Parameters may be declared on the type directly.
- Parameters may carry a type annotation.
- The body assigns to `this`.

```
class Shape(type: str):
    this.type = type
```

- An equivalent form declares attributes and an `init` function.

```
class Shape:
    type: str

    def init(type: str):
        this.type = type
```

- An argument that is not supplied leaves the attribute `null`.

```
class Item(name: str):
    this.name = name

item1 = Item("NAME-1")
item2 = Item()
```

- `item1` is `{ "id": "item1", "name": "NAME-1" }`.
- `item2` is `{ "id": "item2", "name": null }`.

### Instances and identity

- Creating an instance registers it in the class's list.
- The variable name becomes the instance `id`.
- An instance created without a variable name is given a generated `id`.
- Creating an instance returns the instance itself.

```
class Vehicle:
    pass

Vehicle()
```

- `Vehicle.length` is `1`.
- `Vehicle[0].id` is not `null`.

### Addressing instances

- By index: `Name[0]`.
- By id: `Name["id"]`.
- By query: `Name.find(...)`.

```
class Student:
    pass

user0 = Student()
```

- `Student["user0"]` is `{ "id": "user0" }`.
- `Student.find(student => student.id == "user0")` is the same instance.

### Subtypes

- A subtype names its supertype after the colon.
- `super(...)` invokes the supertype constructor.
- Subtype instances are registered in the subtype's list.

```
class Vehicle(make: str):
    this.make = make

class Truck: Vehicle
    def init(make, payload):
        super(make)
        this.payload = payload

truck1 = Truck("Volvo", 12000)
```

- `truck1` is `{ "id": "truck1", "make": "Volvo", "payload": 12000 }`.
- `Truck.length` is `1`.
- Class-level rules on the supertype apply to subtype instances; see [NUC 5](nuc-0005.md).

### Redefining a type

- Re-declaring a type does not clear the class list or the instance list.
- Existing instances keep the properties they had.
- Attributes added by the new definition are `null` on existing instances.

```
class Message:
    pass

$Message.read = false
message1 = Message()

class Message(payload: str):
    this.payload = payload
```

- `message1.read` is `false`.
- `message1.payload` is `null`.
- A later `Message("MESSAGE")` has both.

### Deleting instances

- `delete` on an instance removes it from the state and its class list.
- It returns whether anything was removed.
- Deletion is refused while the instance still has properties.
- A variable name is reusable once its instance is deleted.

```
class Circle:
    pass

circle1 = Circle()
delete circle1
```

- `Circle["circle1"]` is `null`.
- Using `circle1` raises `ReferenceError("circle1 is not defined")`.
- `delete circle1` returns `true`; deleting something undefined returns `false`.

```
class Channel:
    pass

channel1 = Channel()
channel1.frequency = 440
```

- `delete channel1` raises `TypeError("Cannot delete object 'channel1'")`.
- After `delete channel1.frequency`, `delete channel1` succeeds.
- The same applies when the property holds an object rather than a value.

- An instance may also be deleted by reference, including through a variable holding its id.

```
delete Item["item1"]
```

## Errors

| Condition | Error |
| --- | --- |
| Creating an instance of an undeclared type | `ReferenceError("<Name> is not defined")` |
| Assigning an instance of an undeclared type to a property | `ReferenceError("<Name> is not defined")` |
| Deleting an instance that still has properties | `TypeError("Cannot delete object '<id>'")` |
| Using a deleted instance | `ReferenceError("<id> is not defined")` |

- The undeclared-type error is raised the same way for a plain assignment, a property assignment, and a class-level assignment.
