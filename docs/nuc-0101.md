## Abstract

- Propose `SELECTION |> atDepth(DISTANCE)` to retain exactly the steps at
  `DISTANCE`, using the shortest-path distances already defined for `depth`.
- Keep the selected steps' order, fields, distances and observations. A later
  walk still measures from its own input, and accepted `depth`, state, path
  and hypothetical-difference stages retain their behavior.
- Reuse `depth`'s limit validation, undefined deferral, argument evaluation,
  shadowing and transaction contract. Recognize only the contextual pipeline
  call; ordinary identifiers and calls named `atDepth` remain ordinary.
- This continuous Reasoning enhancement requires pre-executed accepted-syntax
  counterparts, independent per-case lexer-token comparison and every hard
  build, test and backward-compatibility criterion.
- This pushed Draft allocates the number only. It records no implementation,
  evaluation result, performance claim or acceptance decision.

## Motivation

- A graph query can ask for one layer rather than every step up to a radius:
  direct supports, direct consequences or the next layer of an explanation.
- Accepted `depth(n)` includes nearer steps. Expressing one exact layer with
  accepted stages requires removing the selection at `depth(n - 1)`, with a
  separate zero-distance branch.
- Name that graph selection directly without changing traversal, provenance,
  numeric coercion, model membership or any accepted source form.
- The caller's one uniform draw selected Reasoning enhancement, index 3 of
  the five live eligible categories, with probability `1/5` and no redraw.
  Graph-layer selection is the proposal's primary purpose.
