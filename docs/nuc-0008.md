# NUC 8 -- Functions

```

Title: Functions
Author: Can Mingir <canmingir@gmail.com>
Status: Draft
Type: Standards Track
Created: 31-Jul-2026
Requires: 1, 2, 6
```

## Abstract

- Specifies function definition, calls, arguments as dependencies, lambdas, and returns.
- A function lives in the state; redefining it updates everything that calls it.
- A call in an assignment is a dependency on both the function and its arguments.

## Motivation

- Shared logic should be written once and stay shared, including when it changes.
- A call that captured only its result would leave every caller stale after a redefinition.
- Lambdas are how the language queries lists and class lists, so they must participate in dependencies too.

## Rationale

- **A function is state, not syntax.** Defining it registers it, so redefining is an ordinary update that propagates to callers -- the same rule that governs variables.
- **Arguments are dependencies.** `number = generate(random)` follows `random`, because a call in an assignment states a relationship like any other expression.
- **A parameter shadows the outer name.** Otherwise a lambda parameter would silently capture state that happens to share its name.

## Specification

### Defining a function

- `def` defines a function in the state.
- The body is indented.
- A function with no `return` yields `null`.

```
def multiply(first_factor, second_factor):
    product = first_factor * second_factor
    return product
```

```
def copy(val):
    b = val
```

- Calling `copy(a)` returns `null`.
- Adding `return val` makes it return the argument.

### Calls as dependencies

- A call in an assignment records a dependency on its arguments.
- The result updates when an argument changes.

```
def generate(number):
    return number * 10

random = 10
number = generate(random)
```

- `number` is `100`.
- After `random = 20`, it is `200`.

- A call may be combined with other operators.

```
z = multiply(x, y) + 1
```

- Calls may be nested.

```
total = increment(double(seed))
```

- With `seed` `5`, `total` is `11`; after `seed = 10`, `21`.

### Redefinition

- Redefining a function updates existing dependents.

```
def fee(amount):
    return amount * 0.1

base = 200
charge = fee(base)
```

- `charge` is `20`.
- After redefining `fee` to `amount * 0.2`, `charge` is `40`.
- After `base = 300`, `charge` is `60`.

### Returns

- A function may return a value, a reference, or an assignment.
- The value of an assignment is the assigned value.
- Multiple `return` statements are allowed; the first reached wins.

```
def sign(n):
    if n > 0:
        return "POSITIVE"
    else if n < 0:
        return "NEGATIVE"
    return "ZERO"
```

- `sign(-4)` is `"NEGATIVE"`, `sign(0)` is `"ZERO"`, `sign(7)` is `"POSITIVE"`.

```
def test(a):
    return a = 2
```

- Calling it returns `2`.
- Assigning an object returns the object; the caller's argument is unchanged.

### Recursion

- A function may call itself.

```
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

- With `number` `5`, the result is `120`; after `number = 6`, `720`.

### Lambdas

- A lambda may be written in three forms, all equivalent.
- Lambdas are the argument to list and class-list functions.

```
list.find(function(element) { return element == 3 })
list.find(element => { return element == 2 })
list.find(element => element == 1)
```

- Parentheses around the body are permitted.

### Parameter shadowing

- A lambda parameter shadows an outer name.
- The outer name is unaffected.

```
element = 38.5

samples.find(element => element == 38.8)
```

- The parameter is used, not the outer `element`.

### Calls over lists and class lists

- A call over a class list is a dependency on the list.
- Adding, removing, or changing instances re-evaluates it.

```
age = 8
student = Student.find(s => s.age == age)
```

- `student` is the student aged `8`.
- After `age = 9`, it is the student aged `9`.

- Calls may be chained, and each parameter is a dependency.

```
list = Result.filter(r => r.score > lowerThreshold).filter(r => r.score < upperThreshold)
```

- Changing either threshold re-filters.
- A property may be read from a call's result.

```
reading = Sensor.find(s => s.code == code).reading
```

### Functions in class-level rules

- A call may appear in a class-level assignment.
- It depends on both the instance's properties and the outer arguments.

```
def discount(price, rate):
    return price - price * rate / 100

$Product.sale = discount($Product.price, percent)
```

- With `price` `200` and `percent` `10`, `sale` is `180`.
- After `percent = 25`, it is `150`.

### The value property as an argument

- `.value` passes the current value without recording a dependency.

```
label = tag("N", seed.value)
```

- `label` does not follow later changes to `seed`.

## Errors

| Condition | Error |
| --- | --- |
| Calling an unknown function of a built-in object | `TypeError("<Object>.<name> is not a function")` |
| Calling an unknown function of a list | `TypeError("<list>.<name> is not a function")` |
| An argument that is not defined | `ReferenceError("<name> is not defined")` |

- If a function throws, the calling transaction is rolled back and the caller's previous value is kept; see [NUC 9](nuc-0009.md).
