# Nucleoid - Python Implementation

Python implementation of the Nucleoid project.

## Setup

1. Create and activate the virtual environment:
   ```bash
   # On Windows
   python -m venv venv
   venv\Scripts\activate

   # On Unix/MacOS
   python3 -m venv venv
   source venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Development

Add your Python code in the appropriate directories and update `requirements.txt` as needed.
